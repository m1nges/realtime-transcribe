# Диктовка

Голосовой ввод в любое поле Windows. Зажимаешь клавишу, говоришь, отпускаешь, и текст появляется там, где стоит курсор: в браузере, Telegram, Word, редакторе кода, где угодно.

- **Бесплатно.** Речь распознаётся прямо на компьютере моделью Whisper, без облака и подписок.
- **Внизу экрана стеклянная плашка** со звуковой волной, пока идёт запись.
- **Слова-паразиты убираются**: «ну», «типа», «короче», «как бы», «э-э» и повторы.
- **Лёгкая.** Пока не диктуешь, программа не нагружает процессор, а микрофон включается только пока зажата клавиша.

## Установка

1. Скачай `Dictate.exe` со страницы [Releases](https://github.com/m1nges/realtime-transcribe/releases).
2. Запусти его. Windows может показать синее окно «Система Windows защитила ваш компьютер», потому что программа не подписана платным сертификатом. Нажми **«Подробнее» → «Выполнить в любом случае»**.
3. Откроется окно установки. Выбери папку: туда встанет программа, модели распознавания (от 0.5 до 1.6 ГБ) и настройки. Там же можно включить автозапуск и ярлык на рабочем столе.
4. Нажми «Установить». Программа запустится, откроются настройки, а рядом с часами появится её значок. Ярлык появится в меню «Пуск».
5. При первом запуске программа один раз скачает модель распознавания. Когда всё будет готово, придёт уведомление.

Готово: зажми **правый Ctrl** и говори.

## Обновления

Программа раз в сутки проверяет, не вышла ли новая версия. Если вышла, придёт уведомление, а в меню значка появится «Вышла версия X — скачать». Чтобы обновиться, скачай новый `Dictate.exe` из [Releases](https://github.com/m1nges/realtime-transcribe/releases) и просто запусти его. Он сам закроет старую версию, встанет на её место в папке установки и запустится. Настройки и модели сохранятся.

## Как пользоваться

| Что сделать | Как |
|---|---|
| Надиктовать текст | Поставь курсор в поле, зажми правый Ctrl, говори, отпусти |
| Отменить запись | Не отпуская Ctrl, нажми любую другую клавишу |
| Открыть настройки | Клик по значку в трее, или ярлык «Диктовка» в «Пуске» |
| Временно выключить | Значок в трее → «Пауза» |
| Закрыть программу | Значок в трее → «Выход» |
| Запускать вместе с Windows | Настройки → «Запускать вместе с Windows» |

Сочетания вроде Ctrl+C и Ctrl+V работают как обычно, запись от них не включается.

## Какую модель выбрать

Программа сама определяет, какой у тебя компьютер, и показывает в настройках совет с кнопкой «Применить». Если хочешь выбрать сам:

| Компьютер | Где считать | Модель |
|---|---|---|
| Видеокарта NVIDIA (GeForce, RTX) с 4 ГБ памяти и больше | Видеокарта NVIDIA | Точная |
| NVIDIA, но памяти меньше 4 ГБ | Видеокарта NVIDIA | Быстрая |
| Видеокарта AMD или Intel, встроенная графика | Процессор | Быстрая |
| Мощный процессор (8+ ядер) без NVIDIA | Процессор | Быстрая, а если путает слова, то Средняя |
| Слабый ноутбук | Процессор | Быстрая |
| Не уверен | Авто | Авто |

Чтобы программа работала на видеокарте NVIDIA, ей нужно один раз скачать библиотеку ускорения, 553 МБ. Кнопка для этого появится в настройках.

## Чистка текста

- **Слова-паразиты**: включено по умолчанию, бесплатно, работает на компьютере.
- **Умная чистка через OpenRouter**: выключена по умолчанию. Нейросеть лучше убирает оговорки и расставляет знаки препинания. Нужен свой ключ с [openrouter.ai/keys](https://openrouter.ai/keys), фраза стоит доли цента, в настройках виден счётчик потраченного. Текст при этом уходит на сервер OpenRouter. Если сервер не ответил за 3 секунды или нет интернета, текст чистится обычным способом.

## Безопасность и приватность

- **Голос не уходит в интернет.** Распознавание работает полностью на компьютере.
- **Сеть используется только в четырёх случаях:**
  - один раз скачивается модель с [Hugging Face](https://huggingface.co);
  - один раз скачивается библиотека для видеокарты NVIDIA с PyPI, и её контрольная сумма проверяется;
  - раз в сутки программа спрашивает у GitHub номер последней версии (выключается в настройках);
  - OpenRouter, если ты сам его включил.
- **Входящих подключений нет:** программа ничего не открывает наружу и не работает как сервер.
- **Клавиатура.** Чтобы работала горячая клавиша, программа видит нажатия. Она только сравнивает их с выбранной клавишей, ничего не записывает и никуда не отправляет.
- **Микрофон** включается только пока зажата клавиша. Всё остальное время он выключен, и значок микрофона в Windows не горит.
- **Ключ OpenRouter** хранится зашифрованным средствами Windows (DPAPI): расшифровать его может только твоя учётная запись на твоём компьютере.
- **Надиктованный текст нигде не сохраняется**, в лог попадают только длительности.
- **Буфер обмена.** Для вставки программа на долю секунды кладёт текст в буфер, а потом возвращает туда то, что было.
- **Код открыт**, его можно проверить и собрать самому.

## Где лежат файлы и как удалить

Всё хранится в папке, которую ты выбрал при установке: программа, модели, настройки и лог. В системе остаются только ярлыки и пара записей в реестре (путь к папке, автозапуск, пункт в «Приложениях»).

Удалить программу можно как любую другую: **Параметры → Приложения → Диктовка → Удалить**. Удаление закроет программу, уберёт ярлыки и автозапуск и сотрёт папку установки вместе с моделями.

## Сборка из исходников

Нужен Python 3.13.

```bash
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt pyinstaller
build.bat
```

Готовый файл появится в `dist\Dictate.exe`. Запустить без сборки: `.venv\Scripts\python app.py`.

Устройство кода:

| Файл | Что в нём |
|---|---|
| `app.py` | Точка входа: трей, горячая клавиша, очередь распознавания |
| `engine.py` | Микрофон, распознавание (faster-whisper), чистка, вставка, настройки |
| `overlay.py` | Стеклянная плашка с волной |
| `webui.py` | Окна настроек и установки (WebView2), обновление и удаление |
| `ui/` | Вёрстка окон |
